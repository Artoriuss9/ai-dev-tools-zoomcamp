# Agent-extension security notes

Module 5 was not completed for this project. There is no agent extension pack,
MCP server, project hook, or autonomous agent to grant permissions to or audit.
The project therefore makes no claim that it satisfies the Module 5 extension
pack rubric.

The project-instruction file is guidance for human developers and coding
assistants, not an executable guardrail. If agent extensions are introduced in
future work, review tool allowlists, filesystem boundaries, network access,
secret handling, and approval requirements before enabling them. Use
`docs/permissions.md` as the minimum data-access policy.
